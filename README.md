# Строительные web-инструменты

Публичный сайт: https://nikolarsen.github.io/

Статический сайт без сборки и сервера: чистый HTML, CSS, JS. Публикуется из ветки `master`
корня репозитория через GitHub Pages.

## Что внутри

- `index.html` — главная: список инструментов, установка PWA
- `tools/*.html` — калькуляторы (плитка, обои, стяжка, краска), каждый самодостаточный
- `manifest.webmanifest` — описание приложения (иконки, ярлыки, standalone)
- `sw.js` — service worker, кэширует оболочку для офлайна
- `assets/` — стили, общий скрипт, иконки

## Правки

1. Меняете файлы, поднимаете `VERSION` в `sw.js` (иначе у вернувшихся посетителей останется старый кэш).
2. `git add -A && git commit -m "..." && git push`.
3. GitHub Pages пересобирает сайт за 20–60 секунд.
